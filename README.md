# 🍻 Kroeg der Kroegspelen

Een speelse website met 20 klassieke drankspelletjes op één plek: klik op een
spel en krijg direct de volledige uitleg.

## Bekijk de site

Open `index.html` in je browser, of host de map als statische site (bv. via
GitHub Pages).

## Functies

- Homegrid met alle spellen, zoeken en filteren op categorie
- Detailpagina per spel: benodigdheden, spelregels, tips
- 🍾 Spin de fles — laat het lot een spel kiezen
- ⭐ Favorieten (onthouden in je browser)
- 🎲 Dobbelsteen / kaart / munt-tool, handig tijdens het spelen
- 🌙☀️ Kroeg (donker) / Terras (licht) thema

De spelregels in `games.js` zijn een startpunt op basis van eigen research —
pas ze gerust aan naar je eigen huisregels.
